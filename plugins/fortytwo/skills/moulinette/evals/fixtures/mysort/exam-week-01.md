# Week 01 Exam — mysort

## Task
Write `mysort.py`. It reads whitespace-separated integers from stdin and prints them sorted ascending, space-separated, on one line.

Constraints:
- Implement the sort yourself. `sorted()`, `list.sort()`, and any sorting library are forbidden.
- Invalid input (a non-integer token) prints an error to stderr and exits non-zero.

## Self-check
Your program must produce this exactly:

```
$ echo "5 3 9 1 7" | python mysort.py
1 3 5 7 9
```

Then try it with your own inputs before calling it done.
